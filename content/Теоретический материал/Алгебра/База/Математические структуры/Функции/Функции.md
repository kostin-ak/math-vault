## Функции

### Основные определения
- #Определение ==**Функцией**== называется правило $f$, по которому каждому [[Основы теории множеств#^item|элементу]] $x$ из [[Основы теории множеств#^set|множества]] $X$ ставится в соответствие единственный [[Основы теории множеств#^item|элемент]] $y$ из [[Основы теории множеств#^set|множества]] $Y$. ^func
- #Определение ==**Областью определения**== [[#^func|функции]] называется [[Основы теории множеств#^set|множество]] всех допустимых значений [[Мономы (одночлены)#^a7cd6a|переменной]] $x$.
    #Обозначение $D(f)$ или $X$ ^e67eb4
- #Определение ==**Областью ([[Основы теории множеств#^set|множеством]]) значений**== [[#^func|функции]] называется [[Основы теории множеств#^set|множество]] всех значений $y$, которые принимает [[#^func|функция]].
    #Обозначение $E(f)$ или $Y$
- #Определение ==**Графиком [[#^func|функции]]**== называется [[Основы теории множеств#^set|множество]] всех [[Основные понятия планиметрии#^point|точек]] [[Основные понятия планиметрии#^plain|плоскости]] с координатами $(x,y)$, где $y=f(x)$. ^41d13c

4. Словесное описание
	#Пример [[#^func|Функция]] $f(x)$ определена как квадрат аргумента ($f(x) = x^2$) для всех возможных аргументов $x$ из [[#^e67eb4|области определения]] $D(f) = \mathbb{R}$. 
	Это означает, что для каждого значения $x$ мы можем вычислить $f(x)$, подставив его в формулу. 
	Например, если $x = 2$, то $f(2) = 2^2 = 4$. График [[#^func|функции]] $f(x) = x^2$ представляет собой параболу, направленную вверх, и проходящую через точку $(0, 0)$. Она симметрична относительно оси $y$ и достигает своего минимального значения в точке $x = 0$.
### Свойства функций:

#### Монотонность:
- #Определение [[#^func|Функция]] называется ==**возрастающей**== на [[Основы теории множеств#^set|множестве]], если для любых $x_1, x_2$ из [[#^e67eb4|области определения]], из $x_1 < x_2$ следует $f(x_1) < f(x_2)$
    #Обозначение $\forall x_1, x_2 \in X: x_1 < x_2 \Rightarrow f(x_1) < f(x_2)$
- #Определение [[#^func|Функция]] называется ==**убывающей**== на [[Основы теории множеств#^set|множестве]], если для любых $x_1, x_2$ из [[#^e67eb4|области определения]], из $x_1 < x_2$ следует $f(x_1) > f(x_2)$
    #Обозначение $\forall x_1, x_2 \in X: x_1 < x_2 \Rightarrow f(x_1) > f(x_2)$

#### Чётность:
- #Определение [[#^func|Функция]] называется ==**чётной**==, если для любого $x$ из [[#^e67eb4|области определения]] выполняется $f(-x) = f(x)$
- #Определение [[#^func|Функция]] называется ==**нечётной**==, если для любого $x$ из [[#^e67eb4|области определения]]  выполняется $f(-x) = -f(x)$

#### Периодичность:
- #Определение [[#^func|Функция]] называется ==**периодической**== с периодом $T$, если для любого $x$ из [[#^e67eb4|области определения]] выполняется $f(x+T) = f(x)$
### Операции над функциями:
1. Сложение: $(f+g)(x) = f(x) + g(x)$
2. Вычитание: $(f-g)(x) = f(x) - g(x)$
3. Умножение: $(f \cdot g)(x) = f(x) \cdot g(x)$
4. Деление: $(\frac{f}{g})(x) = \frac{f(x)}{g(x)}$
5. Композиция (сложение  [[#^func|функций]]): $(f \circ g)(x) = f(g(x))$

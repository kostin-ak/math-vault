## [[Бесконечность#^infinity|Бесконечные]] числовые [[Основы теории множеств#^set|множества]]
### Основные определения:
- #Оперделение ==**Числовым**== [[Основы теории множеств#^set|множеством]] называют [[Основы теории множеств#^set|множество]] [[Основы теории множеств#^item|элементами]] которого являются только числа. 
- #Оперделение ==**Бесконечным**== [[Основы теории множеств#^set|множеством]] называют [[Основы теории множеств#^set|множество]] [[Основы теории множеств#^753af3|мощность]] которого равна бесконечности
### Основные числовые множества
1. Натуральные числа.
	#Оперделение ==**Натуральными числами**== называют все такие числа, с помощью которых можно пересчитать что-либо. 
	#Оперделение[[Основы теории множеств#^set|Множеством]] ==**натуральных чисел**== называют [[Основы теории множеств#^set|множество]] состоящее из всех [[#^natural|натуральных чисел]]. 
	#Обозначение $$\mathbb{N} = \{1,2,3, ..., n,...\}$$
	^naturals
2. Целые числа.
	#Оперделение [[Основы теории множеств#^set|Множеством]] ==**целых чисел**== называют [[Основы теории множеств#^set|множество]] состоящее из всех [[#^natural|натуральных чисел]], противоположных им и нуля.
	#Обозначение $${\mathbb{Z}}$$
	#Оперделение $$\mathbb{Z} = \{\pm 1, \pm2, \pm3, ..., \pm n, ...\}$$
	#Оперделение $$\mathbb{Z} = \{x|\forall a \in \mathbb{N} : x = a\} \cup \{y|\forall b \in \mathbb{N} : y=-b\} \cup \{0\}$$^integers
3. Рациональные числа
	#Оперделение [[Основы теории множеств#^set|Множеством]] ==**рациональных чисел**== называют [[Основы теории множеств#^set|множество]] состоящее из всех чисел представимых в виде [[Обыкновенные дроби#^b3c030|обыкновенной дроби]].
	 #Обозначение $$\mathbb{Q}$$
	 #Оперделение $$\mathbb{Q} = \{\frac{n}{k}|n \in \mathbb{Z}, k\in\mathbb{N}\}$$
	 #Пример $$\frac{1}{5} \in \mathbb{Q}, \ -\frac{1}{2} \in \mathbb{Q}, \ 5 \in \mathbb{Q}, \ 5\frac{1}{3} \in \mathbb{Q}$$^rational
4. Иррациональные числа. 
	 #Оперделение [[Основы теории множеств#^set|Множеством]] ==**иррациональных чисел**== называют [[Основы теории множеств#^set|множество]] состоящее из всех чисел которые невозможно представить в виде [[Десятичные дроби#^108c58|конечной]] [[Десятичные дроби#^83c410|непериодической]] [[Десятичные дроби#^11862e|десятичной дроби]].
	#Обозначение $$\mathbb{I}$$
	#Оперделение $$\mathbb{I} = \{x|x \neq \frac{n}{k}, \text{где } n \in \mathbb{Z}, l \in \mathbb{N}\}$$
	#Пример $$\sqrt{2} \in \mathbb{I}, \: \pi \in \mathbb{I}, \: e \in \mathbb{I}$$
	^irrational
5. Действительные (вещественные) числа. 
	 #Оперделение [[Основы теории множеств#^set|Множеством]] ==**действительных чисел**== называют [[Основы теории множеств#^set|множество]] состоящее из всевозможных комбинаций [[#^rational|рациональных]] и [[#^irrational|иррациональных]] чисел.
	 #Обозначение $$\mathbb{R}$$
	 ^real
6. Комплексные числа
	#Оперделение **==Мнимой единицей==** называют такое число $i$, что $i^2=-1$.
	#Оперделение ==**Мнимым числом**== называют число, состоящее из [[#^real|действительно]] коэффициента, помноженного на [[#^complex|мнимую единицу]] $i$. 
	#Оперделение [[Основы теории множеств#^set|Множеством]] ==**комплексных чисел**== называют [[Основы теории множеств#^set|множество]] состоящее из всевозможных комбинаций [[#^real|действительных]] и [[#^complex|мнимых]] чисел. 
	#Обозначение $$\mathbb{C}$$
	#Оперделение $$\mathbb{C} = \{a+bi|a, b \in \mathbb{R}\}$$
	^complex
